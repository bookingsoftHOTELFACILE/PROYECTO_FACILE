## Descripción

El desarrollo de BookingSoft deberá realizarse utilizando Visual Studio Code como editor de código y Antigravity como asistente de desarrollo con inteligencia artificial. Estas herramientas constituyen una restricción del proceso de desarrollo y no una característica del sistema para el usuario final.

---

## Justificación

El establecimiento de herramientas de desarrollo estándar garantiza consistencia en el entorno de trabajo del equipo, facilita la colaboración, y define el contexto técnico bajo el cual se construye y valida el proyecto BookingSoft.

---

## Criterios de cumplimiento

- El desarrollo del código fuente de BookingSoft se realiza utilizando Visual Studio Code.
- El asistente de desarrollo con inteligencia artificial utilizado en el proyecto es Antigravity.

---

## Restricciones / Consideraciones

- Este es un requisito del proceso de desarrollo, no un requisito del sistema de software para sus usuarios finales.
- Las configuraciones específicas de los entornos de desarrollo (extensiones, ajustes de VS Code, etc.) pueden definirse en documentación técnica adicional del proyecto.
- Este requisito no impide el uso de herramientas complementarias de apoyo (navegadores, clientes REST, gestores de base de datos, etc.) siempre que las herramientas principales establecidas sean las definidas en este requisito.

---

## Verificación

- Verificar que el equipo de desarrollo utiliza Visual Studio Code como editor principal durante el desarrollo del proyecto.
- Verificar que Antigravity es el asistente de IA utilizado para apoyar el desarrollo de BookingSoft.
